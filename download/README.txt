微光小屋 · Glimmer Nook
Android 调试版 v0.4.0

安装
1. 在 Android 手机上下载 glimmer-nook-v0.4.0-debug.apk。
2. 允许浏览器或文件管理器安装未知来源应用。
3. 点击 APK 安装。已经装过旧版的话，直接覆盖安装即可，本地记录会保留。

这一版新增
- 「小灯记得」：在日记里写下怕冷、喜欢靠窗、最近很累这些小事，可以分类、编辑、忘掉。
- 聊天页默认是免费的离线小灯：不联网、不调用模型、不产生 API 费用。
- 离线小灯会参考你写下的记忆回应，并明确标注自己不是大模型。
- 连接 DeepSeek API 后，最近的记忆会一起作为聊天上下文；可随时切回离线小灯。
- 记忆和日记一起保存在本机，随导出备份保存；离线聊天不上传。

说明
- 这是调试签名版本，适合自己安装使用，不建议上架应用商店。
- 所有打卡、日记和记忆保存在手机 WebView 的本地存储中，不上传。
- 换设备前请在应用内「小屋 → 导出备份」导出 JSON。
- 支持 Android 7.0（API 24）及以上。
- 版本号：0.4.0 (versionCode 5)
