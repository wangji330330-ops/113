微光小屋 · Glimmer Nook
Android 调试版 v0.2.0

安装
1. 在 Android 手机上下载 glimmer-nook-v0.2.0-debug.apk。
2. 允许浏览器或文件管理器安装未知来源应用。
3. 点击 APK 安装。已经装过旧版的话，直接覆盖安装即可，本地记录会保留。

这一版新增
- 人物形象自由搭配：头 / 面 / 身 / 腿 / 鞋。
- 13 个可停留场景，点击场景物件会触发小灯对话。
- 设置里的版本检查与更新日志。
- 启动时联网检查新版本，有新版会跳转到 APK 下载页。

说明
- 这是调试签名版本，适合自己安装使用，不建议上架应用商店。
- 所有打卡数据保存在手机 WebView 的本地存储中，不上传。
- 换设备前请在应用内「小屋 → 导出备份」导出 JSON。
- 支持 Android 7.0（API 24）及以上。
- 版本号：0.2.0 (versionCode 2)
