微光小屋 · Glimmer Nook
Android 调试版 v0.3.1

安装
1. 在 Android 手机上下载 glimmer-nook-v0.3.1-debug.apk。
2. 允许浏览器或文件管理器安装未知来源应用。
3. 点击 APK 安装。已经装过旧版的话，直接覆盖安装即可，本地记录会保留。

这一版新增
- 新增 DeepSeek 网页版入口：Android 在应用内浏览器打开，保留登录 Cookie。
- 网页版 / PWA 的入口会在新标签打开 chat.deepseek.com。
- 网页版免费登录使用；登录和对话由 DeepSeek 页面完成，不会自动写进小屋。
- 想自动保存对话、写进日记，仍然需要使用 API Key。
- 上一版：今日随机场景、按日期归档的日记本、页面切换优化。

说明
- 这是调试签名版本，适合自己安装使用，不建议上架应用商店。
- 所有打卡和日记数据保存在手机 WebView 的本地存储中，不上传。
- 换设备前请在应用内「小屋 → 导出备份」导出 JSON。
- 支持 Android 7.0（API 24）及以上。
- 版本号：0.3.1 (versionCode 4)
- 如果 DeepSeek 网页版在应用内无法登录，点浏览器页面右上角「浏览器」切换系统浏览器。
