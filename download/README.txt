微光小屋 · Glimmer Nook
Android 调试版 v0.3.0

安装
1. 在 Android 手机上下载 glimmer-nook-v0.3.0-debug.apk。
2. 允许浏览器或文件管理器安装未知来源应用。
3. 点击 APK 安装。已经装过旧版的话，直接覆盖安装即可，本地记录会保留。

这一版新增
- 今日页每次打开/刷新随机换一个场景，13 个场景可以在首页直接点击。
- 新增按日期归档的日记本；不再限制字数，空一行自动分段。
- 日记本里可以和小灯聊天：可选接入 DeepSeek V4.1 Flash，需要自己的 API Key。
- 页面切换改为即时渲染，场景缩略图分批绘制。
- 底部导航：今日 / 小事 / 日记 / 奖励 / 小屋。

联网聊天说明
- 在「日记 → 和小灯聊聊 → 连接 DeepSeek」填写自己的 API Key。
- API 模型名是 deepseek-flash（DeepSeek V4.1 Flash）。
- Key 和聊天记录只保存在这台设备上，不进入导出备份。
- 没有 Key 也可以正常使用日记、场景、打卡和奖励。

说明
- 这是调试签名版本，适合自己安装使用，不建议上架应用商店。
- 所有打卡和日记数据保存在手机 WebView 的本地存储中，不上传。
- 换设备前请在应用内「小屋 → 导出备份」导出 JSON。
- 支持 Android 7.0（API 24）及以上。
- 版本号：0.3.0 (versionCode 3)
